# LDH Programming Essentials

Ein JetBrains / CLion Plugin für C & C++ Entwickler.

## Features
- **Code-Notizen (`//`) Scanner:** Durchsucht automatisch C-Quelldateien nach Notizen und Kommentaren (`//`, `/* ... */`, `TODO`, `FIXME`, `NOTIZ`, etc.).
- **Click-to-Code Navigation:** Klick auf eine Notiz im Tool-Window öffnet sofort die C-Datei und springt direkt zur entsprechenden Codezeile.
- **Projektweiter Notizblock:** Persistenter Notizblock mit Option, alle gefundenen Code-Kommentare mit einem Klick zu importieren.
- **Scope-Box & Function Highlighting:** Automatische Hervorhebung von Funktionen und aktuellem Block-Scope.
- **Copy Function Action:** Schnelles Kopieren von Funktionen über das Gutter-Icon oder Tastenkürzel.
